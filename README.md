Student Performance Factors Analysis

📌 About

An analytical project that examines key factors influencing student academic performance using data visualization to uncover patterns, trends, and actionable insights.

🎯 Objective

To analyze how different academic, behavioral, and demographic factors impact student performance and to identify the most influential variables affecting outcomes.

🗂️ Dataset Description

The dataset contains information related to student performance factors, including:

Academic scores

Study-related attributes

Attendance and engagement indicators

Socio-demographic variables

🔍 Key Analyses Performed

Student Performance Distribution Analysis

Factor-wise Impact Analysis

Comparison of Academic Metrics

Trend and Pattern Identification

Performance Consistency Analysis

📈 Key Insights

Student performance varies significantly based on specific academic and behavioral factors.

Certain variables show a stronger influence on outcomes, highlighting areas for targeted academic improvement.

Data visualization helps clearly identify performance gaps and trends.

🛠️ Tools & Technologies

Tableau – Dashboard creation and visual analysis

Microsoft Excel – Data cleaning and preparation

📁 Project Files

Student Performance Factors.xlsx – Raw dataset

Student Performance Factors analysis.twbx – Tableau packaged workbook

🚀 Value of the Project

Demonstrates data analysis and visualization skills

Shows ability to derive insights from real-world datasets

Useful for academic institutions and educators to understand performance drivers

📌 Conclusion

This project highlights how data-driven analysis can be used to understand student performance and support informed academic decision-making.
